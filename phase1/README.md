# Phase 1: SQL, Statistics, Probability, and Power BI

This phase focuses on the first capstone section and forms the analytical foundation for the full project.

## Objectives
- Load and validate the dataset in SQLite
- Explore the relationship between traffic volume and weather/time variables
- Calculate descriptive statistics and correlation
- Apply probability and conditional probability concepts
- Build a Power BI dashboard that communicates the key patterns clearly

## Main tasks
1. Import the dataset into SQLite
2. Write SQL queries to summarize traffic behavior
3. Calculate descriptive statistics and correlation
4. Compute probability and conditional probability measures
5. Build a dashboard in Power BI for communication and insight translation
6. Summarize key findings for integration into the final capstone report

## Recommended deliverables
- SQL script with queries
- summary statistics calculations
- probability analysis notes
- Power BI dashboard screenshots or exported visuals
- interpretation of key findings

## Required dataset path
The raw file should be available here before running the Phase 1 work:

- data/raw/Metro_Interstate_Traffic_Volume.csv

## Suggested analysis questions
- Which hours have the highest traffic volume?
- What is the relationship between weather and traffic?
- Do holidays materially affect traffic patterns?
- Are certain months or times of day more congested?
- How strong is the relationship between temperature, rain, and volume?
