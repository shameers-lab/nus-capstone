# Phase 2: Data Pipeline, Cleaning, and Feature Engineering

This phase turns the raw traffic dataset into a reproducible, model-ready dataset.

## Objectives
- validate data schema and file integrity
- handle missing values and duplicate records
- detect and manage invalid or extreme values
- engineer time and weather features
- create a cleaned dataset for downstream ML work

## Main deliverables
- validated raw dataset
- cleaned dataset
- engineered feature set
- reproducible pipeline script
- logging and documentation

## Core files
- python/phase2_pipeline.py
- output/cleaned_traffic_data.csv
- output/feature_summary.json
- output/phase2_summary.md
